API

Unter /api bietet die Pipeline eine JSON-Schnittstelle für Agenten und Skripte: Dokumente suchen, ein Dokument mit Text und Entitäten abrufen, Entitäten über alle Dokumente auflisten und Fragen mit Quellenangaben beantworten lassen. Alles, was die Oberfläche zeigt, ist darüber auch maschinell erreichbar.

auf einem anderen Rechnerhttp://<IP-des-Rechners>:8999/api (dazu APP_BIND=0.0.0.0 und ein API_TOKEN)

Token

{% if token %}

Ein API_TOKEN ist gesetzt. Jeder Aufruf braucht den Kopf Authorization: Bearer <Token>, sonst antwortet die API mit 401. Den Wert findest du in der .env (im Browser-Terminal: grep API_TOKEN .env).

{% else %}

Kein API_TOKEN gesetzt: Die API ist ohne Anmeldung offen. Das ist nur in Ordnung, solange die Pipeline wie voreingestellt nur lokal erreichbar ist (APP_BIND=127.0.0.1). Mit API_TOKEN=... in der .env und compose restart app wird sie geschützt.

{% endif %}
